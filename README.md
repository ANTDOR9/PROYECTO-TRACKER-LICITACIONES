# Monitor de Licitaciones - Brighter Peru

Dashboard de oportunidades de negocio VIGENTES con el Estado peruano
(pantallas interactivas, pizarras digitales, kioscos, equipamiento audiovisual).
Consulta la API publica de SEACE/OECE en vivo.

## Desplegar en Streamlit Cloud
1. Subir estos archivos a un repositorio de GitHub.
2. En share.streamlit.io -> Create app -> elegir el repo.
3. Main file path: streamlit_app.py
4. Deploy.

## Correr local
```
pip install -r requirements.txt
streamlit run streamlit_app.py
```
